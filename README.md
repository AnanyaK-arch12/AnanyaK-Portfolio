# Ananya K. — Personal Portfolio

A responsive personal portfolio website built to showcase my background, skills, projects, and contact information.

## Tech Stack

* HTML5
* CSS3
* JavaScript

## Features

* Responsive layout for desktop and mobile
* Mobile navigation menu
* Hero section with profile image
* About, skills, and projects sections
* Contact section and social links
* Custom visual design with animations

## Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
